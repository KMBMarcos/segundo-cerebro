# AetherList (astro-todo)

## Resumen
Aplicación de lista de tareas (todo) con Astro, sin frameworks JS: TypeScript y CSS vanilla.

## Stack
Astro 6 · TypeScript/CSS vanilla (npm) · Requiere Node ≥ 22.12

## Comandos clave
```bash
npm run dev      # desarrollo
npm run build
npm run preview
```

## Gotchas / pitfalls
- Estado en `localStorage` con claves `aetherlist-*` (no hay backend).
- Sin frameworks: no instalar React/Svelte a menos que sea necesario.
